# Choice Architecture and Nudges
Lectures: L15. Sources: [[datac104/Lecture Notes/L15 Making Decisions|L15: making decisions]].

## Definition and Significance
Choice architecture arranges an environment so some actions become easier, more visible, or more likely. A nudge encourages a preferred outcome while leaving alternatives formally available.

The course calls this second-order decision-making: designers choose the conditions within which others choose. Digital systems can intensify it through personalized, repeated feedback and adjustment, described as hypernudging.

---

## Examples

- Positioning healthier food prominently in a lunch line changes attention and access.
- Facebook's voting experiment shows interface prompts affecting turnout without selecting users' preferred candidates.
