# Narrative Template
Lectures: L19. Sources: [[datac104/Lecture Notes/L19 Data Futures|L19: data futures]].

## Definition and Significance
A narrative template is a shared cultural pattern used to organize particular stories. It supplies recognizable actors, causal relationships, conflicts, and outcomes through which technologies become meaningful.

L19 compares templates to cookie cutters: they select aspects of reality while leaving others outside the frame. Analysis asks where a template came from, whose viewpoint it normalizes, and what alternatives it obscures.

---

## Examples

- The 1984 template centers dictatorial state surveillance.
- A heroic technological-progress story foregrounds exceptional inventors and conquest while marginalizing care or collective infrastructure.
