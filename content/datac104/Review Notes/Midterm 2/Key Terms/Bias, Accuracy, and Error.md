# Bias, Accuracy, and Error
Lectures: L16. Sources: [[datac104/Lecture Notes/L16 Fairness Automated Decision-Making I|L16: fairness]].

## Definition and Significance
Accuracy describes predictive performance relative to a chosen target; error describes discrepancies from it; bias can describe systematic patterns in those discrepancies or broader inequalities in data and treatment. These meanings should be specified rather than treated as interchangeable.

L16 asks how targets and reference outcomes were produced. A technically accurate prediction can reproduce an institution's unequal practices, while choosing which errors matter requires ethical judgment.

---

## Examples

- COMPAS's unequal false-positive and false-negative patterns differ from its cross-group calibration.
- Arrest records can accurately record institutional action without measuring all underlying crime.
