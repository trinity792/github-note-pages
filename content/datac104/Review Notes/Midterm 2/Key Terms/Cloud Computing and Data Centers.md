# Cloud Computing and Data Centers
Lectures: L24. Sources: [[datac104/Lecture Notes/L24 Making Silicon Valley III|L24: Silicon Valley III]].

## Definition and Significance
Cloud computing supplies remotely managed computing resources and applications, often as rented services. Data centers are the physical facilities housing the servers, storage, networking, and supporting infrastructure that make those services possible.

The course challenges an immaterial image of digital activity. Cloud providers concentrate ownership over infrastructure on which other firms depend, connecting the earlier platform economy to contemporary capital-intensive AI.

---

## Examples

- Amazon Web Services, Microsoft Azure, and Google Cloud exemplify rented computing infrastructure.
- AI models require chips, servers, buildings, and energy even when users encounter only a software interface.
